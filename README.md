# Weather
Python program to get weather information by city name

## Stuff it does
* Gets weather info for a city you type in.
* Saves previous searches in `data.json`
* Downloads a cool picture from Pixabay based on the weather description.
* Checks if the image is already on your computer before downloading it again.

## What you need

Create an .env file like .env.exemple

Create a data.json file with an empty list

python -m venv .venv

source .venv/Scripts/activate

pip install -r req.txt

python main.py
